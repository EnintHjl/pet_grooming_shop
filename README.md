## 🚀 快速上手

1. **克隆仓库**
   ```bash
   git clone git@github.com:EnintHjl/pet_grooming_shop.git
   cd pet_grooming_shop
   ```

2. **直接运行**
   - 双击打开 `宠物洗护店.html`
   - 或在 VS Code 中使用 Live Server 插件运行

3. **部署上线**
   可直接部署到 GitHub Pages、Vercel 或其他静态网站托管平台。
